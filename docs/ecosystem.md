# Fluent Ecosystem

Fluent is a Bible translation platform made up of several services.

## Frontend repos

- [fluent-web](https://github.com/eten-tech-foundation/fluent-web) — Web front-end. React + TypeScript + Vite.
- [fluent-mobile](https://github.com/eten-tech-foundation/fluent-mobile) — Mobile companion app. React Native + Expo + TypeScript.

## Backend/infra (good to know exists, not where you'll work)

- [fluent-api](https://github.com/eten-tech-foundation/fluent-api) — Core API (Node/Hono + Drizzle ORM/Postgres).
- [fluent-ai](https://github.com/eten-tech-foundation/fluent-ai) — AI services (Python/FastAPI).
- [fluent-platform](https://github.com/eten-tech-foundation/fluent-platform) — Orchestrates the whole stack (containers, cross-repo docs).

## Other useful references

- [fluent-kb](https://github.com/eten-tech-foundation/fluent-kb) — Product knowledge base (ODDKit).
- [fluent-user-manual](https://github.com/eten-tech-foundation/fluent-user-manual) — End-user docs.
- [fluent-design](https://github.com/eten-tech-foundation/fluent-design) — Design-focused demo/sandbox repo.

## TL;DR tech stack

Web = React/TS/Vite. Mobile = React Native/Expo/TS. API = Node (Hono), AI = Python (FastAPI), DB = Postgres.
